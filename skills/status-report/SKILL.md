# Status report

Write the report in this shape, and keep it under 15 lines:

1. **Headline** – one sentence: the overall state (done / in progress / blocked).
2. **Facts** – 2–5 bullets with concrete, checked details (numbers, names, paths).
3. **Risks or blockers** – only if there are any.
4. **Next step** – one bullet: what should happen next, and who does it.

Rules:
- Only report what you or another agent actually checked. Mark guesses as guesses.
- When the report goes to IRC, the headline alone must make sense, because long replies are cut.
- See `template.md` for an example.
